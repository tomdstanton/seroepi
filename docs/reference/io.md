# 📦 Data I/O & Patito Schema Stewardship

The `io` module provides Patito schema models and bioinformatic parsers for ingesting and validating outputs from Kleborate and Pathogenwatch pipelines into standard `SeroEpi` datasets.

```python
from seroepi.io import (
    SampleModel,
    BaseGenotypeParser,
    PathogenwatchKleborateParser,
    PathogenwatchGenomeParser,
)
```
