# 📚 Enumerations & Constants

The `constants` module defines central Enumeration types for plot routing, domain namespaces, temporal intervals, spatial resolution levels, and distance metrics across `SeroEpi`.

```python
from seroepi.constants import (
    PlotType,
    Domain,
    TemporalResolution,
    SpatialResolution,
    DistanceMetricType,
)
```
